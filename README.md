# Лабораторна робота 2. Квадрат Полібія та шифр Гронсфельда

Навчальна консольна програма з курсу «Програмні технології захисту інформації».
Реалізує три режими (зашифрування і розшифрування) для українського та латинського алфавітів:

| Режим (`--mode`) | Що робить | Ключ (`--key`) |
| --- | --- | --- |
| `polybius-coordinates` | кодує символи координатами «рядок стовпець» у квадраті 6×6 | ключове слово |
| `polybius-row-shift` | замінює символ символом із наступного рядка того самого стовпця (циклічно) | ключове слово |
| `gronsfeld` | поліалфавітна підстановка зі зсувами-цифрами | рядок цифр |

`coordinates` і `row shift` — це **різні** алгоритми: перший є кодуванням (шифротекст — числа),
другий — проста одноалфавітна підстановка.

> **Лише для навчання.** Ці алгоритми не забезпечують конфіденційності й автентичності.
> Не застосовуйте їх для паролів, персональних даних чи іншої чутливої інформації.
> Для реального захисту використовуйте стандартизовані алгоритми через перевірені бібліотеки
> (наприклад, AES-GCM).

## Вимоги

- Node.js 20 або новіший (перевірено на v22.22.2)
- Зовнішніх залежностей немає, `npm install` не потрібен

## Запуск

```bash
node bin/ciphers2.js --help
```

Алфавіт (`--lang uk` або `--lang lat`) **обирається явно**; автоматичного визначення мови немає.

```bash
# координати Полібія (український), ключове слово БЕЗПЕКА
node bin/ciphers2.js encrypt --mode polybius-coordinates --lang uk --key БЕЗПЕКА --text "Слава"
node bin/ciphers2.js decrypt --mode polybius-coordinates --lang uk --key БЕЗПЕКА --text "44 35 16 21 16"

# координати: окрема видима операція вилучення пробілів
node bin/ciphers2.js encrypt --mode polybius-coordinates --lang uk --key БЕЗПЕКА --strip-spaces --text "Слава України"

# циклічний зсув за рядками (латинський)
node bin/ciphers2.js encrypt --mode polybius-row-shift --lang lat --key SECURITY --text "Hello"

# Гронсфельд: ключ — рядок цифр, початкові нулі зберігаються
node bin/ciphers2.js encrypt --mode gronsfeld --lang uk --key 31415 --text "Слава Україні"
node bin/ciphers2.js encrypt --mode gronsfeld --lang lat --key 2718 --text "Hello World"

# показати активний квадрат 6×6
node bin/ciphers2.js square --lang uk --key БЕЗПЕКА
```

Файли UTF-8: `--in вхід.txt --out вихід.txt`. Текст можна передати і через стандартний вхід.
Покроковий режим: `node bin/ciphers2.js interactive` (у полі тексту `@шлях/до/файлу.txt` читає файл).
Правила підготовки тексту: `node bin/ciphers2.js rules`.

### Параметри

| Параметр | Призначення |
| --- | --- |
| `--mode`, `-m` | `polybius-coordinates`, `polybius-row-shift`, `gronsfeld` |
| `--lang`, `-l` | `uk` або `lat` (обов'язковий) |
| `--key`, `-k` | ключове слово (Полібій) або рядок цифр (Гронсфельд) |
| `--text`, `-t` / `--in`, `-i` | джерело тексту (або стандартний вхід) |
| `--out`, `-o` | записати результат у файл (атомарно, без BOM) |
| `--strip-spaces` | вилучити пробільні символи перед зашифруванням; лише `polybius-coordinates` + `encrypt`; кількість вилучених друкується |

Без `--out` результат друкується з завершальним переносом рядка. Під час розшифрування координат
з файлу чи каналу програма знімає **один** завершальний перенос рядка; будь-який інший зайвий пробіл
лишається помилкою.

### Коди завершення

| Код | Значення |
| --- | --- |
| 0 | успіх |
| 1 | помилка ключа, токена чи тексту (повідомлення українською у stderr) |
| 2 | помилка аргументів командного рядка |

## Тести

```bash
npm test          # або: node --test
```

Покрито: 6 контрольних векторів із методички (шифрування і розшифрування), квадрат (розмір, унікальність,
порядок символів ключа), координати (11, 66, помилки 00, 17, 67, 71), циклічність row shift, обидві мови
(Ґ Є І Ї, A Z), ключі Гронсфельда (початковий нуль, 9, довгий, порожній, лише нулі), форматування,
UTF-8 файли, зворотність на 10 повідомленнях для кожного режиму та мови, генеративні перевірки
(фіксований seed), консольний інтерфейс.

## Відтворюваний експеримент

```bash
npm run demo      # або: node scripts/demo.js
```

Шифрує `samples/plain_uk.txt` і `samples/plain_lat.txt` трьома режимами, перевіряє розшифрування й
записує файли в `results/` (звіт — `results/summary.md`).

## Специфікація обробки тексту (коротко)

- Кодування UTF-8; рядки обробляються як послідовності кодових точок Unicode
- Нормалізація: NFC → верхній регістр → повторний NFC; непарні сурогати відхиляються
- Українські літери (33) і квадрат: літери + цифри `0 1 2`; латинські (26) і квадрат: літери + цифри `0–9`
- Квадрат 6×6: унікальні символи ключового слова (перша поява), далі решта базового набору по порядку
- Ключове слово: лише символи квадрата, щонайменше одна літера
- `coordinates` (strict): приймає лише символи квадрата; токени «рядок стовпець» через **один** пробіл;
  токен — рівно дві цифри від 1 до 6. Значення `00`, `17`, `67`, `71`, одна цифра чи текст — помилка.
  Значення `61` **коректне** (рядок 6, стовпець 1)
- `row shift`: символ квадрата → символ наступного рядка (6 → 1), розшифрування — вгору; інші символи лишаються
- `gronsfeld`: змінюються лише літери вибраного алфавіту; пробіли, цифри, розділові знаки й літери
  іншого алфавіту не змінюються і не просувають ключ. Ключ — рядок цифр, не порожній, не лише нулі

## Структура

```
bin/ciphers2.js        точка входу CLI
src/alphabets.js       алфавіти uk і lat, явний вибір мови
src/text.js            NFC, регістр, перевірка Unicode, вилучення пробілів
src/square.js          побудова, перевірка й таблиці пошуку квадрата 6×6
src/polybius.js        режими coordinates і row shift
src/gronsfeld.js       шифр Гронсфельда
src/api.js             єдина точка виклику режимів
src/fileio.js          UTF-8 файли, атомарний запис
src/cli.js             аргументи, команди, інтерактивний режим
src/errors.js          CipherError, UsageError
test/                  автоматизовані тести (node:test)
testlib/helpers.js     генератор випадкових даних для тестів
scripts/demo.js        відтворюваний експеримент
samples/, results/     власні тексти й результати експерименту
```

Криптографічна логіка не залежить від інтерфейсу: модулі `src/*.js` (крім `cli.js`) нічого не читають
і не друкують. Таблиці пошуку (символ ↔ координата, зсув вниз/вгору) будуються один раз під час
створення квадрата, обробка тексту лінійна.

## Відомі обмеження

- Екранування довільних Unicode-символів у координатному шифротексті не реалізовано; такі символи відхиляються.
- Збереження регістру не реалізовано: усі літери переводяться у верхній регістр.
- Цифри 3–9 не входять до українського квадрата: у `coordinates` вони відхиляються, у `row shift` лишаються без змін.
